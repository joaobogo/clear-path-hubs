## 2. Data & security layer

### 2.1 Database
- 76 tables, **RLS enabled on all 76**. 21 views, 66 user triggers.
- Immutability/lifecycle guards confirmed live: `tg_score_runs_immutable`, `tg_rubric_versions_immutable`, `tg_position_versions_immutable`, `tg_stage_history_immutable`, `tg_evidence_overrides_append_only`, `tg_candidate_matches_publish_gate`, `tg_positions_lifecycle_guard`, `tg_hire_records_lifecycle`.
- Publish gate enforces the "invisible until approved" rule at the database level (`client_visibility='visible'` requires `approved_score_run_id` + `canonical_state='published_to_client'` + `integrity_status='ok'`). **OK.**

Supabase linter: **22 findings**, dominated by
- extensions (`pg_trgm`, `citext`) installed in the `public` schema — S3, C;
- `SECURITY DEFINER` helper functions executable by `anon`/`authenticated` — S2, C (notably `hard_delete_candidate_match` / `hard_delete_position`, which do self-check `is_platform_staff` internally, and `grant_platform_admin_for_taasflow_domain`);
- leaked-password protection (HIBP) disabled — S3, C.

### 2.2 Storage
- Single private bucket `cvs`, 20 objects.
- **No `allowed_mime_types` and no `file_size_limit` configured on the bucket** — the PDF-only and 10 MB rules exist only in application code (`cv-validation.ts`), not at the storage layer. **S2, C.**

### 2.3 Authentication
- Providers: **email/password only**. Password reset via `resetPasswordForEmail`. Invitations via `supabaseAdmin.auth.admin.inviteUserByEmail` (`client.functions.ts:1123,1181`).
- Role assignment: `memberships` table (`platform_admin`, `operations`, `client_admin`, `client_editor`, `client_viewer`) + `user_roles`/`has_role` for system roles. `grant_platform_admin_for_taasflow_domain` auto-grants platform_admin to any confirmed `@taasflow.com` email — **S2, C**: domain-based auto-escalation is an unbounded admin surface if the domain's mail is ever compromised.
- QA persona login (`qaPersonaLogin`) issues magic links, gated by `ENABLE_QA_PERSONA_ACCESS` — verify the flag is unset in production. **S2, U.**
